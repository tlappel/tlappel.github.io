# tlappel.github.io

Personal site built with Jekyll and published through GitHub Pages.

## Preview locally

Open PowerShell in this directory and run:

```powershell
bundle install
bundle exec jekyll serve --livereload
```

Then open <http://127.0.0.1:4000/>. Leave the command running while editing; Jekyll will rebuild the site when files change. Press `Ctrl+C` to stop it.

If Ruby was just installed and `bundle` is not recognized, close and reopen PowerShell so the updated PATH is loaded.
